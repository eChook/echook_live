Race-ready telemetry UI, one family across eChook products.

Typography

Oswald · system sans · mono
Page title — 24px bold text-2xl font-bold
Auth panel title text-3xl font-bold text-primary
Section title text-lg font-semibold + rule
Section eyebrow text-sm uppercase tracking-wide
Body copy sits at 14px, muted zinc, comfortable line height. text-sm text-zinc-600
Micro label · speed (mph) text-[10px] uppercase tracking-wider
24.8 text-2xl font-mono font-bold — every live value

Oswald is brand-only — never body copy or form labels. Anything that changes live (telemetry, timestamps, IDs, ranges) is monospace bold. Missing values render as — or --/--, never blank.

11

Motion, accessibility, dark mode

Motion
Button press — active:scale-95
Data card hover — 200ms, −2px lift
Modal / toast — 150–300ms ease
Ribbon show/hide — ~300ms height + opacity
Live pulse — dots and LIVE chips only
Spinner — animate-spin on ArrowPath, loading only
No continuous background animation, particles, or glowing borders. Every animation pairs with a reduced-motion fallback.
Accessibility floor
Icon-only controls carry accessible names.
Active nav sets aria-current="page".
Modals trap focus, close on Escape and backdrop.
Toasts use role="alert" with manual dismiss.
Status pairs a dot with a label — never colour alone.
Touch targets ≥ 44px on pit-side phones.
Dark mode
Class strategy: .dark on <html>, mode light / dark / system.
Theme applied before first paint by an inline boot script.
color-scheme set so native controls follow.
Light uses zinc, dark uses neutral; muted text in dark leans gray.
Link and inline-action text on dark surfaces uses #f472a0, not raw primary — #cb1557 on #262626 is only 2.7:1. Solid magenta buttons and light-theme links are unchanged.
Every new surface ships both themes in the same class string.

13

Do / Don't

Do
+Use magenta sparingly, as signal.
+Pair every dark style with its light counterpart.
+Live values in mono; the wordmark in Oswald.
+Prefer borders and quiet fills over shadow stacks.
+Confirm destructive or data-lossy actions.
+State retention and privacy next to the action.
Don't
−Recolour the UI around pink backgrounds.
−Add a second brand accent without a semantic reason.
−Set Oswald in body copy or form labels.
−Animate everything that is merely visible.
−Ship light-only screens.
−Wrap every piece of text in a card.
